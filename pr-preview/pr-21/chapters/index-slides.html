Preface

This website collects the lecture notes for CSCI 481, “Deep Learning”, as taught in Spring Quarter 2027 at Western Washington University by Douglas Ezra Morrison.

The course follows the module sequence of Brian Hutchinson’s CSCI 481/581, which he taught from Winter 2021 to Winter 2026.

CSCI 481 builds on DATA 371/471, Machine Learning. Where these notes use an idea that course covers, such as generalization, gradient descent, or logistic regression, they link to its definition in Machine Learning for Data Science (lds) rather than defining it again.

The Calendar lists the topics week by week, and the Syllabus gives the course’s policies. The main reference text is Deep Learning [1], which can be read at no cost on the book’s webpage.
