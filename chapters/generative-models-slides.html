1 Welcome

1.1 Plan for this lecture

The language models chapter drew new text one character at a time from a model of the next character. This lecture draws new images and new data points, with generative models made of neural networks:

  1. an autoencoder, and why it does not say how to make a new image;
  2. a variant whose codes follow a known distribution, so that a new image is a decoded draw from it;
  3. two networks trained against each other, one making data and one spotting the fakes;
  4. a network that learns to remove noise, and makes data by removing it a step at a time.

def mlp(*sizes):
    # Linear layers of the given sizes, with a ReLU between each pair.
    layers = []
    for n_in, n_out in zip(sizes[:-1], sizes[1:]):
        layers += [nn.Linear(n_in, n_out), nn.ReLU()]
    return nn.Sequential(*layers[:-1])


def train_model(model, loss_fn, n_epochs=100, lr=0.003, seed=0):
    # Adam on minibatches of 64 training images; loss_fn(model, batch) is the loss.
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    generator = torch.Generator().manual_seed(seed)
    for epoch in range(n_epochs):
        shuffled = torch.randperm(n_train, generator=generator)
        for start in range(0, n_train, 64):
            loss = loss_fn(model, x_train[shuffled[start:start + 64]])
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()


def show_digits(images, n_cols=8):

2 Autoencoders

2.1 A two-number code

Show code
class Autoencoder(nn.Module):
    # Encodes 64 pixels as `code_size` numbers,
    # and decodes those numbers back to 64 pixels between 0 and 1.

    def __init__(self, code_size=2):
        super().__init__()
        self.encoder = mlp(64, 128, code_size)
        self.decoder = nn.Sequential(mlp(code_size, 128, 64), nn.Sigmoid())

    def forward(self, x):
        return self.decoder(self.encoder(x))


def ae_loss(model, batch):
    # Binary cross-entropy of each pixel against its reconstruction,
    # summed over the pixels and averaged over the images.
    return F.binary_cross_entropy(model(batch), batch, reduction="sum") / len(batch)


_ = torch.manual_seed(1)
autoencoder = Autoencoder()
print(autoencoder)

Autoencoder is an autoencoder whose bottleneck has 2 units, so its encoder turns each image into a code of 2 numbers. Other sources call the code a latent representation or latent variable. ae_loss() treats each pixel value as the probability that the pixel is dark.

3 Drawing new codes

3.1 A distribution for the codes

Exercise 3 (Codes we can draw)

Exercise 3 (Codes we can draw) The codes of Solution 2 follow no distribution we know. What could the encoder output, and the loss add, so that the codes of the training images follow \(\dNf{\vzero, \idmat}\)?

Solution 3

Solution 3. Let the encoder output a normal distribution for each image, with a mean and a standard deviation for each coordinate of the code, and train the decoder on draws from it. Then add to the loss the KL divergence of each of those distributions from \(\dNf{0, 1}\). The penalty pulls every image’s distribution toward the standard normal, so a draw from \(\dNf{\vzero, \idmat}\) lands where the decoder has seen codes. This needs two results: the KL divergence between two normal distributions, and a way to differentiate through a random draw.

3.2 Distance from a standard normal

Exercise 4 (How far is a normal distribution from the standard normal?)

Exercise 4 (How far is a normal distribution from the standard normal?) Let \(q = \dNf{\mu, \sigma^2}\) and \(p = \dNf{0, 1}\). Find the KL divergence \(\kldivf{q}{p}\) as a formula in \(\mu\) and \(\sigma\).

Solution 4

Solution 4. Let \(Z \sim q\), so \(\E{Z} = \mu\) and \(\Var{Z} = \sigma^2\). The log densities are \(\logf{q(z)} = -\frac{1}{2} \logf{2 \pi} - \frac{1}{2} \logf{\sigma^2} - \frac{(z - \mu)^2}{2 \sigma^2}\) and \(\logf{p(z)} = -\frac{1}{2} \logf{2 \pi} - \frac{z^2}{2}\). Then

\[ \begin{aligned} \kldivf{q}{p} &= \E{\logf{q(Z)} - \logf{p(Z)}} && \text{(definition of KL divergence)} \\ &= \E{-\frac{1}{2} \logf{\sigma^2} - \frac{(Z - \mu)^2}{2 \sigma^2} + \frac{Z^2}{2}} && \text{(the } \logf{2 \pi} \text{ terms cancel)} \\ &= -\frac{1}{2} \logf{\sigma^2} - \frac{\E{(Z - \mu)^2}}{2 \sigma^2} + \frac{\E{Z^2}}{2} && \text{(linearity of expectation)} \\ &= -\frac{1}{2} \logf{\sigma^2} - \frac{\sigma^2}{2 \sigma^2} + \frac{\E{Z^2}}{2} && \text{(} \E{(Z - \mu)^2} = \Var{Z} = \sigma^2 \text{)} \\ &= -\frac{1}{2} \logf{\sigma^2} - \frac{\sigma^2}{2 \sigma^2} + \frac{\sigma^2 + \mu^2}{2} && \text{(} \E{Z^2} = \Var{Z} + \E{Z}^2 \text{)} \\ &= -\frac{1}{2} \logf{\sigma^2} - \frac{1}{2} + \frac{\sigma^2 + \mu^2}{2} && \text{(cancel } \sigma^2 \text{)} \\ &= \frac{1}{2} \paren{\mu^2 + \sigma^2 - 1 - \logf{\sigma^2}}. && \text{(collect terms)} \end{aligned} \]

Theorem 1 (KL divergence from the standard normal)

Theorem 1 (KL divergence from the standard normal) For \(\mu \in \reals\) and \(\sigma > 0\),

\[ \kldivf{\dNf{\mu, \sigma^2}}{\dNf{0, 1}} = \frac{1}{2} \paren{\mu^2 + \sigma^2 - 1 - \logf{\sigma^2}} \]

Kingma and Welling [2] derive it in their appendix B.

Proof

Proof. By Solution 4.

3.3 Differentiating through a draw

Exercise 5 (A gradient through a random draw)

Exercise 5 (A gradient through a random draw) An encoder outputs \(\mu\) and \(\sigma\), and the next layer gets a draw \(z\) from \(\dNf{\mu, \sigma^2}\). How can we write \(z\) so that the gradient of the loss reaches \(\mu\) and \(\sigma\)?

Solution 5

Solution 5. Draw \(\noise \sim \dNf{0, 1}\) first, with no parameters involved, and set \(z = \mu + \sigma \noise\). Then \(z \sim \dNf{\mu, \sigma^2}\), and \(z\) is a differentiable function of \(\mu\) and \(\sigma\), with \(\derivf{z}{\mu} = 1\) and \(\derivf{z}{\sigma} = \noise\).

Definition 1 (Reparameterization trick)

Definition 1 (Reparameterization trick) The reparameterization trick writes a draw \(\vz\) from a distribution with parameters \(\vth\) as \(\vz = g_{\vth}(\vnoise)\), where \(\vnoise\) is drawn from a fixed distribution and \(g_{\vth}\) is differentiable in \(\vth\) [2, Sec. 2.4]. For a normal distribution with mean \(\vecf{\mu}\) and standard deviations \(\vecf{\sigma}\), \(\vz = \vecf{\mu} + \vecf{\sigma} \odot \vnoise\) with \(\vnoise \sim \dNf{\vzero, \idmat}\), where \(\odot\) multiplies entry by entry.

3.4 The model

Definition 2 (Variational autoencoder)

Definition 2 (Variational autoencoder) A variational autoencoder has an encoder that maps an input \(\vx\) to vectors \(\vecf{\mu}(\vx)\) and \(\vecf{\sigma}(\vx)\) in \(\reals^k\), and a decoder that maps a code \(\vz \in \reals^k\) back to the space of inputs. In training, the code is a draw \(\vz = \vecf{\mu}(\vx) + \vecf{\sigma}(\vx) \odot \vnoise\) by the reparameterization trick. The loss for \(\vx\) is the reconstruction loss of the decoded \(\vz\) plus \(\sumto{j}{k} \kldivf{\dNf{\mu_j(\vx), \sigma_j(\vx)^2}}{\dNf{0, 1}}\) [2, Secs. 2.3, 3]. To make a new input, decode a draw from \(\dNf{\vzero, \idmat}\).

Example 3 (A variational autoencoder for the digits)

Example 3 (A variational autoencoder for the digits)  

Show code
class VAE(nn.Module):
    # The encoder's 2 * code_size outputs are the means and the log variances.

    def __init__(self, code_size=2):
        super().__init__()
        self.encoder = mlp(64, 128, 2 * code_size)
        self.decoder = nn.Sequential(mlp(code_size, 128, 64), nn.Sigmoid())

    def forward(self, x):
        mu, log_var = self.encoder(x).chunk(2, dim=1)
        z = mu + torch.exp(0.5 * log_var) * torch.randn_like(mu)
        return self.decoder(z), mu, log_var


def vae_loss(model, batch):
    reconstruction, mu, log_var = model(batch)
    fit = F.binary_cross_entropy(reconstruction, batch, reduction="sum")
    kl = 0.5 * (mu**2 + log_var.exp() - 1 - log_var).sum()
    return (fit + kl) / len(batch)


_ = torch.manual_seed(1)
vae = VAE()
train_model(vae, vae_loss)
with torch.no_grad():
    train_mu, train_log_var = vae.encoder(x_train).chunk(2, dim=1)
    noise = torch.randn(train_mu.shape, generator=torch.Generator().manual_seed(2))
    vae_codes = train_mu + torch.exp(0.5 * train_log_var) * noise
    test_mu = vae.encoder(x_test).chunk(2, dim=1)[0]
    vae_mse = F.mse_loss(vae.decoder(test_mu), x_test).item()
vae_code_mean = vae_codes.mean(dim=0).tolist()
vae_code_sd = vae_codes.std(dim=0).tolist()
print(vae_code_mean, vae_code_sd, vae_mse)
[0.025694118812680244, 0.04258835315704346] [1.0070878267288208, 1.0168691873550415] 0.03732502833008766

VAE is a variational autoencoder with codes of 2 numbers, the same layers as Autoencoder, and the KL term of Theorem 1 added to ae_loss(). Its encoder outputs \(\logf{\sigma^2}\) rather than \(\sigma\), so that any real output gives a valid \(\sigma\). After the same training, one draw of the code for each training image gives codes with means 0.03 and 0.04 and standard deviations 1.01 and 1.02, close to the means of 0 and standard deviations of 1 of the standard normal that new codes are drawn from. Decoding \(\vecf{\mu}(\vx)\) gives a test mean squared error of 0.037, against 0.036 for the autoencoder of Solution 1.

Remark 1 (The loss as a bound)

Remark 1 (The loss as a bound). When the reconstruction loss is the negative log probability that the decoder gives \(\vx\), as the binary cross-entropy of vae_loss() would be for pixels that are each 0 or 1, the negative of the variational autoencoder’s loss is a one-draw estimate [2, Sec. 2.3] of what Kingma and Welling [2, Sec. 2.2] call the variational lower bound, a lower bound on the log probability of \(\vx\). Many sources call it the evidence lower bound (ELBO).

4.2 A forger and a detective

Exercise 7 (Real or made up?)

Exercise 7 (Real or made up?) A network turns random noise into made-up eruptions. We have the 272 real eruptions but no formula for their density. How could a second network tell the first one how to make its eruptions look more real?

Solution 7

Solution 7. Train the second network as a classifier that tells real eruptions from made-up ones. The first network then changes its weights to make the classifier call its eruptions real. As each network improves, the other has a harder task.

Definition 3 (Generative adversarial network (GAN))

Definition 3 (Generative adversarial network (GAN)) A generative adversarial network, or GAN, has a generator \(G\), which maps a draw \(\vz\) of noise to a data point \(G(\vz)\), and a discriminator \(D\), which gives the probability \(D(\vx)\) that a data point \(\vx\) is real. They are trained in turn, \(D\) to maximize and \(G\) to minimize

\[ V(D, G) = \E{\logf{D(\vecf{X})}} + \E{\logf{1 - D(G(\vecf{Z}))}}, \]

where \(\vecf{X}\) is a real data point and \(\vecf{Z}\) is the noise [7, Sec. 3].

Example 4 (A GAN for Old Faithful)

Example 4 (A GAN for Old Faithful)  

Show code
_ = torch.manual_seed(0)
generator_net = mlp(2, 64, 64, 2)
discriminator = mlp(2, 64, 64, 1)
adam = dict(lr=1e-3, betas=(0.5, 0.999))
g_optimizer = torch.optim.Adam(generator_net.parameters(), **adam)
d_optimizer = torch.optim.Adam(discriminator.parameters(), **adam)
draws = torch.Generator().manual_seed(0)
real_label, fake_label = torch.ones(64, 1), torch.zeros(64, 1)
for step in range(3000):
    real = standardized[torch.randint(0, len(standardized), (64,), generator=draws)]
    fake = generator_net(torch.randn(64, 2, generator=draws))
    # The discriminator's step: logits, so the loss is cross-entropy on D.
    d_loss = (
        F.binary_cross_entropy_with_logits(discriminator(real), real_label)
        + F.binary_cross_entropy_with_logits(discriminator(fake.detach()), fake_label)
    )
    d_optimizer.zero_grad()
    d_loss.backward()
    d_optimizer.step()
    # The generator's step: make D call the fakes real.
    g_loss = F.binary_cross_entropy_with_logits(discriminator(fake), real_label)
    g_optimizer.zero_grad()
    g_loss.backward()
    g_optimizer.step()

Both networks are MLPs with two hidden layers of 64 units, trained for 3,000 steps on the standardized eruptions. The discriminator returns a logit, so binary_cross_entropy_with_logits, with label 1 for the real points and 0 for the made-up ones, is \(-V(D, G)\) for a minibatch. The generator’s loss is \(-\logf{D(G(\vz))}\), rather than \(V(D, G)\). Of the made-up eruptions, 63% last longer than 3 minutes, against 64% of the real ones. But the made-up points lie along one thin curve. Along the long end of that curve, the generator gives each eruption length nearly one wait; along the short end, it gives nearly one length for a range of waits. Among the eruptions longer than 3 minutes, the waits have standard deviation 3.7 minutes, against 6.0 for the real ones. The generator matches where the data lie better than how they spread.

Remark 2 (The generator’s loss in practice)

Remark 2 (The generator’s loss in practice). Example 4 follows Goodfellow et al. [7, Sec. 3], who train \(G\) to maximize \(\logf{D(G(\vecf{Z}))}\) instead of minimizing \(V(D, G)\). This gives larger gradients early in training, when \(D\) rejects the made-up points easily.

4.3 The best detective

Exercise 8 (The best discriminator)

Exercise 8 (The best discriminator) Fix the generator, and let \(p_g\) be the density of its made-up points and \(p\) that of the real ones. Which \(D(\vx)\) maximizes \(V(D, G)\) of Definition 3?

Solution 8

Solution 8. A point \(G(\vecf{Z})\) made up by the generator has density \(p_g\), so \(\E{\logf{1 - D(G(\vecf{Z}))}} = \int p_g(\vx) \logf{1 - D(\vx)} \, d\vx\). Writing the first expectation the same way puts \(V\) in one integral over \(\vx\):

\[ V(D, G) = \int \paren{p(\vx) \logf{D(\vx)} + p_g(\vx) \logf{1 - D(\vx)}} \, d\vx. \]

The integral is largest when \(D(\vx)\) maximizes the integrand at each \(\vx\) separately. With \(a = p(\vx)\), \(b = p_g(\vx)\) and \(u = D(\vx)\), the integrand is \(f(u) = a \logf{u} + b \logf{1 - u}\) on \(0 < u < 1\). For \(a, b > 0\),

\[ \begin{aligned} f'(u) &= \frac{a}{u} - \frac{b}{1 - u} && \text{(differentiate)} \\ 0 &= \frac{a}{u} - \frac{b}{1 - u} && \text{(set } f'(u) = 0 \text{)} \\ 0 &= a (1 - u) - b u && \text{(multiply by } u (1 - u) \text{)} \\ 0 &= a - (a + b) u && \text{(collect the terms in } u \text{)} \\ u &= \frac{a}{a + b}. && \text{(solve for } u \text{)} \end{aligned} \]

\(f''(u) = -a / u^2 - b / (1 - u)^2 < 0\), so that \(u\) is the maximum. Where \(b = 0\) the integrand increases toward \(u = 1\), and where \(a = 0\) it increases toward \(u = 0\); \(a / (a + b)\) gives those values too. The best discriminator is \(D(\vx) = p(\vx) / \paren{p(\vx) + p_g(\vx)}\). Where the generator’s density equals the data’s, the best discriminator is \(\frac{1}{2}\).

Theorem 2 (The optimal discriminator)

Theorem 2 (The optimal discriminator) For a fixed generator whose points have density \(p_g\), and data with density \(p\), the discriminator that maximizes \(V(D, G)\) is

\[ D^*(\vx) = \frac{p(\vx)}{p(\vx) + p_g(\vx)} \]

Goodfellow et al. [7, Sec. 4.1] prove it as their proposition 1.

Proof

Proof. By Solution 8.

5 Adding and removing noise

5.1 Adding noise

Exercise 9 (Adding noise twice)

Exercise 9 (Adding noise twice) Start from a data point \(\vx_0\), and add noise twice:

\[ \vx_1 = \sqrt{1 - \beta_1} \, \vx_0 + \sqrt{\beta_1} \, \vnoise_1, \qquad \vx_2 = \sqrt{1 - \beta_2} \, \vx_1 + \sqrt{\beta_2} \, \vnoise_2, \]

with \(\vnoise_1\) and \(\vnoise_2\) independent draws from \(\dNf{\vzero, \idmat}\). What is the distribution of \(\vx_2\) given \(\vx_0\)?

Solution 9

Solution 9. Substitute \(\vx_1\) into \(\vx_2\):

\[ \begin{aligned} \vx_2 &= \sqrt{1 - \beta_2} \paren{\sqrt{1 - \beta_1} \, \vx_0 + \sqrt{\beta_1} \, \vnoise_1} + \sqrt{\beta_2} \, \vnoise_2 && \text{(substitute } \vx_1 \text{)} \\ &= \sqrt{1 - \beta_2} \sqrt{1 - \beta_1} \, \vx_0 + \sqrt{1 - \beta_2} \sqrt{\beta_1} \, \vnoise_1 + \sqrt{\beta_2} \, \vnoise_2 && \text{(distribute)} \\ &= \sqrt{(1 - \beta_1)(1 - \beta_2)} \, \vx_0 + \sqrt{(1 - \beta_2) \beta_1} \, \vnoise_1 + \sqrt{\beta_2} \, \vnoise_2. && \text{(} \sqrt{a} \sqrt{b} = \sqrt{a b} \text{)} \end{aligned} \]

The last two terms are independent normal vectors with mean \(\vzero\), so their sum is normal with mean \(\vzero\) and covariance

\[ \begin{aligned} \paren{(1 - \beta_2) \beta_1 + \beta_2} \idmat &= \paren{\beta_1 - \beta_1 \beta_2 + \beta_2} \idmat && \text{(expand)} \\ &= \paren{1 - (1 - \beta_1)(1 - \beta_2)} \idmat. && \text{(factor)} \end{aligned} \]

So \(\vx_2\) given \(\vx_0\) is \(\dNf{\sqrt{\bar\alpha_2} \, \vx_0, (1 - \bar\alpha_2) \idmat}\), where \(\bar\alpha_2 = (1 - \beta_1)(1 - \beta_2)\).

Definition 4 (Forward diffusion process)

Definition 4 (Forward diffusion process) A forward diffusion process with noise levels \(\beta_1, \dots, \beta_T\) between 0 and 1 turns a data point \(\vx_0\) into \(\vx_1, \dots, \vx_T\) by

\[ \vx_t = \sqrt{1 - \beta_t} \, \vx_{t - 1} + \sqrt{\beta_t} \, \vnoise_t, \qquad t = 1, \dots, T, \]

with independent \(\vnoise_t \sim \dNf{\vzero, \idmat}\) [8, Sec. 2]. We write \(\bar\alpha_t \eqdef \prod_{s = 1}^{t} (1 - \beta_s)\); Ho et al. [8, Sec. 2] also write \(\alpha_t\) for \(1 - \beta_t\), which these notes do not use.

Theorem 3 (Noise added in one step)

Theorem 3 (Noise added in one step) In a forward diffusion process, \(\vx_t\) given \(\vx_0\) is \(\dNf{\sqrt{\bar\alpha_t} \, \vx_0, (1 - \bar\alpha_t) \idmat}\), so \(\vx_t = \sqrt{\bar\alpha_t} \, \vx_0 + \sqrt{1 - \bar\alpha_t} \, \vnoise\) with \(\vnoise \sim \dNf{\vzero, \idmat}\) [8, Sec. 2].

Proof

Proof. By induction on \(t\). For \(t = 1\), \(\bar\alpha_1 = 1 - \beta_1\) and the statement is the definition. If it holds for \(t - 1\), then \(\vx_t = \sqrt{1 - \beta_t} \paren{\sqrt{\bar\alpha_{t - 1}} \, \vx_0 + \sqrt{1 - \bar\alpha_{t - 1}} \, \vnoise'} + \sqrt{\beta_t} \, \vnoise_t\), where \(\vnoise' \sim \dNf{\vzero, \idmat}\) depends only on \(\vnoise_1, \dots, \vnoise_{t - 1}\) and so is independent of \(\vnoise_t\). The steps of Solution 9, with \(\bar\alpha_{t - 1}\) in place of \(1 - \beta_1\) and \(\beta_t\) in place of \(\beta_2\), give mean \(\sqrt{\bar\alpha_t} \, \vx_0\) and covariance \((1 - \bar\alpha_t) \idmat\).

5.2 Removing noise

Exercise 10 (Undoing the noise)

Exercise 10 (Undoing the noise) A network looks at \(\vx_t\) and guesses the noise \(\est{\vnoise}\) that Theorem 3 added to \(\vx_0\). What estimate of \(\vx_0\) follows from its guess?

Solution 10

Solution 10. Solve \(\vx_t = \sqrt{\bar\alpha_t} \, \vx_0 + \sqrt{1 - \bar\alpha_t} \, \est{\vnoise}\) for \(\vx_0\):

\[ \est{\vx}_0 = \frac{\vx_t - \sqrt{1 - \bar\alpha_t} \, \est{\vnoise}}{\sqrt{\bar\alpha_t}}. \]

A network that predicts the noise well can remove it, so predicting the noise is a way to predict the data.

Definition 5 (Denoising diffusion model (denoising diffusion probabilistic model, DDPM))

Definition 5 (Denoising diffusion model (denoising diffusion probabilistic model, DDPM)) A denoising diffusion model, which Ho et al. [8] call a denoising diffusion probabilistic model (DDPM), is defined for a forward diffusion process. It trains a network \(\vnoise_{\vth}(\vx_t, t)\) to predict the noise in \(\vx_t\), by minimizing \(\normsq{\vnoise - \vnoise_{\vth}\paren{\sqrt{\bar\alpha_t} \, \vx_0 + \sqrt{1 - \bar\alpha_t} \, \vnoise, t}}\) over data points \(\vx_0\), steps \(t\) drawn uniformly from \(1, \dots, T\), and \(\vnoise \sim \dNf{\vzero, \idmat}\). To make a new point, it draws \(\vx_T \sim \dNf{\vzero, \idmat}\) and steps back, for \(t = T, \dots, 1\):

\[ \vx_{t - 1} = \frac{1}{\sqrt{1 - \beta_t}} \paren{\vx_t - \frac{\beta_t}{\sqrt{1 - \bar\alpha_t}} \, \vnoise_{\vth}(\vx_t, t)} + \sqrt{\beta_t} \, \vz_t, \]

with \(\vz_t \sim \dNf{\vzero, \idmat}\) for \(t > 1\) and \(\vz_1 = \vzero\) [8, Secs. 3.2, 3.4].
