# Preface

This website collects the lecture notes for [CSCI 481](https://morrison-lab.github.io/swc/course/CSCI-481.html), “Deep Learning”, as taught in Spring Quarter 2027 at [Western Washington University](https://www.wwu.edu/) by [Douglas Ezra Morrison](https://d-morrison.github.io/).

The course follows the module sequence of [Brian Hutchinson](https://cs.wwu.edu/hutchib2)’s CSCI 481/581, which he taught from Winter 2021 to Winter 2026.

CSCI 481 builds on DATA 371/471, Machine Learning. Where these notes use an idea that course covers, such as generalization, gradient descent, or logistic regression, they link to its definition in [*Machine Learning for Data Science* (lds)](https://morrison-lab.github.io/lds/) rather than defining it again.

The [Calendar](../chapters/calendar.llms.md) lists the topics week by week, and the [Syllabus](../chapters/syllabus.llms.md) gives the course’s policies. The main reference text is *Deep Learning* [\[1\]](#ref-goodfellow2016deep), which can be read at no cost on [the book’s webpage](https://www.deeplearningbook.org/).

## References

\[1\]

I. Goodfellow, Y. Bengio, and A. Courville, *Deep learning*. MIT Press, 2016. Available: <https://www.deeplearningbook.org/>
