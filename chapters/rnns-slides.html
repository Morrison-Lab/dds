Brian Hutchinson’s CSCI 481/581 sets the order of topics in these notes, which follow it with his permission; this page covers the part of his module on recurrent networks that deals with training them, and with turning symbols into vectors. The exercises are new.

1 Welcome

1.1 Plan for this lecture

The DATA 471 notes defined recurrent layers, found that their gradients can vanish or explode over long sequences, and defined the LSTM layer that keeps a memory with gates. This lecture trains these layers in PyTorch:

  1. the shapes that nn.RNN takes and returns;
  2. reading a digit one row at a time, then one pixel at a time;
  3. capping the size of the gradient;
  4. LSTM layers and a lighter gated layer;
  5. turning symbols such as letters into vectors that a network can learn.

1.2 The digits as sequences

Show code
import math

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import torch
from torch import nn

_ = torch.manual_seed(481)
digits = pd.read_csv("data/optdigits-test.csv", header=None)
pixels = torch.tensor(digits.iloc[:, :64].to_numpy(), dtype=torch.float32) / 16
y = torch.tensor(digits[64].to_numpy())
n_train = 1200
order = torch.randperm(len(pixels))
x_train, y_train = pixels[order[:n_train]], y[order[:n_train]]
x_test, y_test = pixels[order[n_train:]], y[order[n_train:]]
loss_fn = nn.CrossEntropyLoss()
LR = 0.01
BATCH_SIZE = 32


class Reader(nn.Module):
    # Reads each image as a sequence of `step_size` pixels at a time,
    # with the recurrent layer `layer`, and classifies it from the last state.

    def __init__(self, layer, step_size, hidden_size=32):
        super().__init__()
        self.step_size = step_size
        self.recurrent = layer(step_size, hidden_size, batch_first=True)
        self.out = nn.Linear(hidden_size, 10)

    def forward(self, images):
        sequence = images.reshape(len(images), -1, self.step_size)
        states, _ = self.recurrent(sequence)
        return self.out(states[:, -1])


def make_reader(layer, step_size, seed=1):
    torch.manual_seed(seed)
    return Reader(layer, step_size)


def train(net, n_epochs=10, lr=LR, batch_size=BATCH_SIZE, seed=0, max_norm=math.inf):
    # Adam on the training digits; returns the gradient norm before each step.
    # A finite `max_norm` rescales any larger gradient to that norm.
    optimizer = torch.optim.Adam(net.parameters(), lr=lr)
    generator = torch.Generator().manual_seed(seed)
    norms = []
    for epoch in range(n_epochs):
        net.train()
        shuffled = torch.randperm(n_train, generator=generator)
        for start in range(0, n_train, batch_size):
            batch = shuffled[start:start + batch_size]
            optimizer.zero_grad()
            loss_fn(net(x_train[batch]), y_train[batch]).backward()
            norm = nn.utils.clip_grad_norm_(net.parameters(), max_norm)
            norms.append(norm.item())
            optimizer.step()
    return norms


def accuracy(net):
    # Fraction of the test digits that `net` classifies correctly.
    net.eval()
    with torch.no_grad():
        return (net(x_test).argmax(dim=1) == y_test).float().mean().item()


print(make_reader(nn.RNN, 8))
Reader(
  (recurrent): RNN(8, 32, batch_first=True)
  (out): Linear(in_features=32, out_features=10, bias=True)
)

The exercises use the UCI optical digits [1], split as in the feedforward networks chapter, with 1,200 training images. Reader reads each image as a sequence, step_size pixels at a time, and classifies it with a linear layer on the last hidden state. With step_size=8, each step reads one row of the image. train() runs Adam with learning rate 0.01 and batch size 32.

2 Recurrent layers in PyTorch

2.1 What a recurrent layer returns

Exercise 1 (What nn.RNN returns)

Exercise 1 (What nn.RNN returns) nn.RNN(8, 32, batch_first=True) is a recurrent layer with inputs of length 8 and a hidden state of length 32. It returns two tensors. What are their shapes for the first 16 training digits, each read as a sequence of 8 rows?

Solution 1

Solution 1.

Show code
recurrent = nn.RNN(8, 32, batch_first=True)
rows = x_train[:16].reshape(16, 8, 8)
states, last_state = recurrent(rows)
same_last = torch.equal(states[:, -1], last_state[0])
print(rows.shape, states.shape, last_state.shape, same_last)
torch.Size([16, 8, 8]) torch.Size([16, 8, 32]) torch.Size([1, 16, 32]) True

With batch_first=True, the input has shape \(16 \times 8 \times 8\): 16 sequences of 8 steps, each step a row of 8 pixels. The first output holds the hidden state after every step, with shape \(16 \times 8 \times 32\). The second holds the hidden state after the last step only, with shape \(1 \times 16 \times 32\). Its first dimension counts stacked layers times directions, here 1 layer read in 1 direction [2]. Its entries equal the last step of the first output. Without batch_first=True, PyTorch expects the steps first and the sequences second.

The median gradient norm is 3.3, but the largest is 43, 13 times the median. 4% of the steps have a norm above 10. So after the spikes the network sat in a state that training did not move it out of.

4 Gated layers

4.1 An LSTM

Exercise 6 (An LSTM reading pixels)

Exercise 6 (An LSTM reading pixels) make_reader(nn.LSTM, 1) reads the pixels with an LSTM layer instead, with no clipping. Trained for 20 epochs, does it classify more test digits correctly than the pixel reader of Solution 5?

Solution 6

Solution 6.

Show code
pixel_lstm = make_reader(nn.LSTM, 1)

Show code

Yes. The LSTM classifies 82.1% of the test digits correctly, against 61.6% for the clipped pixel reader. Its cell state \(\vecf{c}_t\) changes only by the gates’ products and sums, with no squashing activation between one step and the next. So a gradient can pass back along the cell state through many steps when the forget gate stays near 1 [4, Sec. 10.10.1]. The LSTM’s largest gradient norm during training was 12.2, against 43 for the pixel reader of Solution 3.

4.2 Two gates instead of three

Definition 1 (Gated recurrent unit (GRU))

Definition 1 (Gated recurrent unit (GRU)) A gated recurrent unit (GRU) layer keeps only a hidden state \(\vhidval_t \in \reals^{H}\), with no separate cell state, and two gates [5]. In the form PyTorch computes [6],

\[\begin{aligned} \vecf{z}_t &= \sigmoidf{\matr{W}_z \vx_t + \matr{U}_z \vhidval_{t-1} + \vecf{b}_z}, &&\text{(update gate)} \\ \vecf{r}_t &= \sigmoidf{\matr{W}_r \vx_t + \matr{U}_r \vhidval_{t-1} + \vecf{b}_r}, &&\text{(reset gate)} \\ \vecf{u}_t &= \tanhf{\matr{W}_u \vx_t + \vecf{b}_u + \vecf{r}_t \odot \paren{\matr{U}_u \vhidval_{t-1} + \vecf{c}_u}}, &&\text{(candidate)} \\ \vhidval_t &= \vecf{z}_t \odot \vhidval_{t-1} + \paren{1 - \vecf{z}_t} \odot \vecf{u}_t. \end{aligned}\]

Here \(\vecf{c}_u\) is a second bias vector, and PyTorch also adds one to \(\matr{U}_z \vhidval_{t-1}\) and to \(\matr{U}_r \vhidval_{t-1}\). Cho et al. [5] apply the reset gate before the matrix, writing \(\matr{U}_u \paren{\vecf{r}_t \odot \vhidval_{t-1}}\) in the candidate, and also put \(\vecf{z}_t\) on the old state. Chung et al. [7] and the DATA 471 notes put \(1 - \vecf{z}_t\) on the old state instead, which swaps the meaning of \(\vecf{z}_t\) near 0 and near 1.

Example 1 (Parameters of nn.GRU and nn.LSTM)

Example 1 (Parameters of nn.GRU and nn.LSTM)  

Show code
def n_params(net):
    return sum(p.numel() for p in net.parameters())


gru_count = n_params(nn.GRU(1, 32))
lstm_count = n_params(nn.LSTM(1, 32))
print(gru_count, lstm_count)
3360 4480

A GRU layer has three blocks of weights, for \(\vecf{z}_t\), \(\vecf{r}_t\) and \(\vecf{u}_t\), where an LSTM layer has four. PyTorch gives each block two bias vectors, one added to \(\matr{W} \vx_t\) and one to \(\matr{U} \vhidval_{t-1}\) [6]. So nn.GRU(1, 32) has \(3 \times 32 \times (1 + 32 + 2) = 3360\) parameters, and nn.LSTM(1, 32) has \(4 \times 32 \times (1 + 32 + 2) = 4480\).

5 Symbols as vectors

5.1 A one-hot vector times a matrix

Exercise 8 (Multiplying a one-hot vector by a matrix)

Exercise 8 (Multiplying a one-hot vector by a matrix) A network that reads text needs each character as a vector. Number the 26 lowercase letters and the space from 0 to 26, so "c" is 2. Count vector entries and matrix rows from 0 as well. Let \(\vecf{e}_2 \in \{0, 1\}^{27}\) be the one-hot encoding of "c", and let \(\matr{E}\) be the \(27 \times 4\) matrix printed below. What is \(\tp{\vecf{e}_2} \matr{E}\)?

Show code
alphabet = "abcdefghijklmnopqrstuvwxyz "
_ = torch.manual_seed(2)
E = torch.randn(len(alphabet), 4).round(decimals=2)
print(E[:4])
tensor([[-1.0400,  0.9200, -1.3000, -1.1100],
        [-1.2200,  1.1700, -1.0600, -0.1200],
        [-0.9100,  0.3500, -0.5700, -0.2400],
        [ 1.0100, -0.7500, -0.2200, -0.4300]])

Solution 8

Solution 8.

Show code
one_hot_c = nn.functional.one_hot(torch.tensor(alphabet.index("c")), len(alphabet)).float()
product = one_hot_c @ E
print(product, E[2], torch.equal(product, E[2]))
tensor([-0.9100,  0.3500, -0.5700, -0.2400]) tensor([-0.9100,  0.3500, -0.5700, -0.2400]) True

Entry \(j\) of \(\tp{\vecf{e}_2} \matr{E}\) is \(\sum_i (\vecf{e}_2)_i \matr{E}_{ij} = \matr{E}_{2j}\), since \((\vecf{e}_2)_i\) is 1 for \(i = 2\) and 0 for every other \(i\). So the product is row 2 of \(\matr{E}\), the third row printed above. Multiplying by a one-hot encoding only looks up a row. A network can skip multiplying by the 26 zeros and read the row directly.

Definition 2 (Embedding layer)

Definition 2 (Embedding layer) An embedding layer maps each of \(K\) symbols, such as characters or words, to a vector in \(\reals^d\). Symbol \(k\) maps to row \(k\) of a \(K \times d\) matrix \(\matr{E}\) of parameters, learned with the rest of the network [4, Sec. 12.4.2]. Row \(k\) is the vector that represents symbol \(k\). The layer equals a linear layer with no bias applied to the one-hot encoding of the symbol, computed by looking up the row.

Example 2 (nn.Embedding)

Example 2 (nn.Embedding)  

Show code
embed = nn.Embedding(len(alphabet), 4)
word = torch.tensor([alphabet.index(ch) for ch in "deep"])
vectors = embed(word)
same_rows = torch.equal(vectors, embed.weight[word])
print(word, vectors.shape, same_rows)
tensor([ 3,  4,  4, 15]) torch.Size([4, 4]) True

nn.Embedding(27, 4) is an embedding layer for the 27 characters, with a \(27 \times 4\) matrix weight [8]. It takes a tensor of whole-number indices, here the indices of the letters of "deep", and returns one row of weight for each. For the 4 letters the result has shape \(4 \times 4\). The two "e"s get the same vector. The returned rows equal the rows of embed.weight at those indices.
